# ADR-0008：可插拔 Local/S3 存储

- 状态：已接受
- 日期：2026-07-21

## 背景

单机部署偏好 Local，生产环境通常需要 S3 兼容对象存储，并且切换后仍要读取历史数据。

## 决策

每个 `image_assets` 记录自己的 `storage_driver`、`storage_container` 和 `storage_key`；系统配置只决定新文件的默认写入驱动。

## 备选方案

只保存完整本地路径或 S3 URL 会把运行环境和签名地址固化到数据库，无法可靠混合读取。

## 影响

Local/S3 可同时存在；切换不自动迁移历史文件，管理员必须保留旧存储并使用一致性扫描验证。
